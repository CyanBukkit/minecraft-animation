让方块人，动起来。

彩贝方映把方块人的姿势放在时间轴上，做法接近 Blender 或 Cinema 4D：轨道、关键帧、拖动时间、记录姿势。代码片段是另一条路，用来生成这些轨道，不会取代时间轴。

  1. 看场景拖动旋转、滚轮缩放、右键平移；点击方块人可以选择角色与关节。
  2. 调动作选择动作预设，或者拖动时间轴，在右侧调节位置与关节。调节会自动记帧，K 记录完整姿态。
  3. 做运镜在自由视角摆好镜头，点击「记录当前镜头」。换一个时间和机位再记录，然后切换「动画镜头」。
  4. 从 Blender 读结构「导入结构」可以读 .blend 的骨架名字，或 glTF 里已经结算好的骨骼动画，并写进当前角色的轨道。栗籽人模的控制骨会自动对应头、身体、胳膊和腿。网页不能打开完整的 Blender 工程。
  5. 导入世界选区可以读 .mca 区域、.schem / .schematic 原理图、.litematic，或一份写了方块名的 JSON。.mca 会先出俯视图：拖紫色框、用 Height / Depth 切层，再载入到营地。也可以点「手填坐标」。整张地图、生物和箱子这一版带不进来。
  6. 加特效在属性里选火花、烟雾、光晕或爆开，点「在当前帧添加」。片段出现在时间轴的特效轨上，到时间就播放，过后消失。
  7. 代码示例「代码示例」把一份写好的作品烘进时间轴，包括走路、挥手、跳跃、镜头和额外方块。烘完以后仍然可以手改关键帧。
  8. 保存作品保存项目导出 JSON；打开 JSON 可以继续编辑。导入 64×64 或等比例高清、经典宽臂 PNG 皮肤，皮肤随项目保存。
  9. 导出画面导出图片保存当前三维画面。录制动画使用浏览器实时录制 WebM，不含声音，速度取决于设备性能。

这是方块人动画工作台，不是 Minecraft 游戏，也不是 Blender。可以直接摆简单的方块地图和方块纹理。细臂皮肤、旧版 64×32 皮肤、以及 Blender 的约束和 IK 结算还不支持。

导入世界选区

还没有框选。在俯视图上拖出一块即可。

选 .mca、region 或整个世界文件夹（可带 level.dat）后，先在俯视图上拖紫色框；Height 是顶、Depth 是底。蓝图 / JSON 没有俯视图时，用手填坐标。载入后选区最小角挪到「放到营地的位置」。大约 64×64×64、实心不超过 8000。生物和箱子不导入。
